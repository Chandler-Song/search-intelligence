## 这本书讲什么

这个时代，越来越多的人正在陷入一种说不清的焦虑——学的东西太多，不知道该学什么；看的信息太多，不知道该信什么；机会就在眼前，不知道怎么抓住。

这本书把这种焦虑叫做**「答案焦虑」**。而真正能让人走出来的，不是更多的知识，而是一种能力：**面对未知，依然有办法。**

这就是**搜商**——发现问题、定义问题、寻找信息、判断信息、整合信息，并把信息转化为行动和结果的综合能力。

核心理念：**收藏不是学习，知道也不是能力。** 真正的搜商，不是"会不会搜索"，而是"面对未知，能不能一路走到解决"。

- **在线阅读链接**：绝对 URL + `#/ch/{两位章号}` 路由，如 `https://chandler-song.github.io/search-intelligence/#/ch/00`。

## 本地预览

```bash
python scripts/start_server.py
```

默认端口 8000，自动打开浏览器。**不要直接双击 `index.html`**（`file://` 协议下 `fetch()` 加载章节会失败）。

推送到 `main` 分支，GitHub Actions 自动部署到 GitHub Pages，约 30 秒生效：

```bash
git add .
git commit -m "update book"
git push origin main
```

### 核心特性

- **商务风格视觉**：深藏青主色 + 金色点缀 + 纯白背景
- **沉浸式阅读**：按 `I` 键进入，侧栏收起，宽度收窄聚焦
- **主题切换**：亮色/暗色双主题
- **字号调节**：10–20 档可调，localStorage 记忆
- **阅读进度**：顶部实时进度条
- **章节内目录**：左侧 TOC 常驻，移动端抽屉
- **键盘快捷键**：`←` `→` 翻章，`I` 沉浸式，`ESC` 退出
- **阅读记忆**：localStorage 记住上次阅读位置
- **章节预加载**：当前章加载后自动预取下一章
