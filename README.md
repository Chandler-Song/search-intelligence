# 搜商 · 图书阅读网站

> 真正决定一个人上限的，不是他知道多少，而是当他不知道的时候，他有没有办法找到答案。

《搜商》一书的在线阅读网站，商务风格设计，支持沉浸式阅读。

## 作者
宋秀强 · 深耕人力资源和职业发展领域的实践者

## 技术栈
- Alpine.js — 交互逻辑
- Tailwind CSS — 样式布局
- marked.js — Markdown 解析
- DOMPurify — XSS 防护

## 本地运行
```bash
python -m http.server 8765
# 浏览器打开 http://localhost:8765
```

## 在线访问
GitHub Pages 部署后自动可用。
