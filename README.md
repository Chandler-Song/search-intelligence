# 搜商

**面对未知时寻找答案的能力**

## 📖 图书概述

这个时代，越来越多的人正在陷入一种说不清的焦虑——学的东西太多，不知道该学什么；看的信息太多，不知道该信什么；机会就在眼前，不知道怎么抓住。

这本书把这种焦虑叫做**「答案焦虑」**。而真正能让人走出来的，不是更多的知识，而是一种能力：**面对未知，依然有办法。**

这就是**搜商**——发现问题、定义问题、寻找信息、判断信息、整合信息，并把信息转化为行动和结果的综合能力。

### ✨ 核心金句

> 收藏不是学习，知道也不是能力。

> 搜商不是"会不会搜索"，是"面对未知，能不能一路走到解决"。

> 短期最值钱的是判断力，长期最值钱的是问题力。

> 愿你永远不知道所有答案，但永远知道如何找到答案。

## 🛠️ 技术实现

### 技术栈

| 技术 | 用途 | 引入方式 |
|------|------|----------|
| [Alpine.js](https://alpinejs.dev/) | 声明式交互框架 | CDN |
| [Tailwind CSS](https://tailwindcss.com/) | 原子化 CSS | CDN |
| [marked.js](https://marked.js.org/) | Markdown 解析 | CDN |
| [DOMPurify](https://github.com/cure53/DOMPurify) | XSS 防护 | CDN |

### 核心特性

- **商务风格视觉**：深藏青主色 + 金色点缀 + 纯白背景，文字对比度 AAA 级
- **沉浸式阅读**：按 `F` 键进入，隐藏所有导航，专注阅读
- **主题切换**：亮色/暗色双主题，按 `T` 键切换
- **字号调节**：小/中/大三档可调
- **阅读进度**：底部实时进度条
- **章节内目录**：右侧 TOC 自动生成，点击跳转
- **键盘快捷键**：`←` `→` 翻章，`F` 沉浸式，`T` 主题，`ESC` 退出
- **阅读记忆**：localStorage 记住上次阅读位置
