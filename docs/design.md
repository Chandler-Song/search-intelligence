# 设计文档：《搜商》图书阅读网站（v2 商务风格）

## 一、项目概述

### 1.1 项目背景
本项目为《搜商》一书构建在线阅读网站。该书由宋秀强所著，共 42 篇内容（序言 + 40 正章 + 终章），主题为"面对未知时寻找答案的能力"。

### 1.2 v2 修订原因
v1 版本存在以下问题：
- **配色对比度不足**：青绿色品牌色（#0F766E）在浅色背景上文字不清晰
- **风格定位偏差**：文艺风格不够专业，需改为商务风格
- **缺少书籍封面**：首页需要展示书籍封面图片

### 1.3 v2 设计目标
- **商务风格**：专业、沉稳、可信赖，参考哈佛商业评论、麦肯锡官网的视觉风格
- **高对比度**：确保所有文字清晰可读，满足 WCAG AA 标准（对比度 ≥ 4.5:1）
- **书籍封面展示**：首页展示自动生成的封面图片（`assets/images/cover.png`）
- **主流视觉传达**：深藏青 + 纯白 + 金色点缀，现代商务审美
- 沉浸式阅读模式、响应式设计、纯前端静态实现

### 1.4 内容来源
- 章节内容：`books-docs/` 目录下 42 个 Markdown 文件
- 作者信息：`author` 文件
- 书籍封面：`assets/images/cover.png`（已自动生成，可后续替换）

## 三、视觉设计（商务风格）

### 3.1 设计风格定位
- **风格**：商务、专业、沉稳、现代
- **参考**：哈佛商业评论、麦肯锡官网、Bloomberg、微信读书商务版
- **核心原则**：高对比度优先 > 美观 > 装饰。文字必须清晰可读。

### 3.2 配色方案

#### 3.2.1 亮色主题（默认）
```
背景色：    #FFFFFF（纯白）
次背景色：  #F8F9FA（极浅灰，用于卡片、侧栏）
主文字色：  #111827（深黑灰，对比度 15:1，极其清晰）
次要文字：  #4B5563（中灰，对比度 7:1，清晰）
弱文字色：  #6B7280（灰，对比度 4.6:1，满足 AA）
分隔线：    #E5E7EB
边框色：    #D1D5DB
```

#### 3.2.2 品牌色（深藏青 — 商务、专业、可信赖）
```
主品牌色：  #1E3A5F（深藏青，用于标题、按钮、链接）
品牌深色：  #15293F（hover 状态）
品牌浅色：  #3B5B7F（辅助）
品牌背景：  #EBF0F5（极浅藏青，用于高亮背景）
```

#### 3.2.3 点缀色（金色 — 高级感，少量使用）
```
金色：      #B8860B（深金，用于装饰线、小标签）
金色浅：    #D4A843（用于 hover）
```

#### 3.2.4 功能色
```
强调/金句：  #1E3A5F（深藏青，金句文字用品牌色，背景用极浅灰）
成功色：    #15803D
警告色：    #B91C1C
```

#### 3.2.5 暗色主题
```
背景色：    #0F172A（深藏青黑）
次背景色：  #1E293B（卡片）
主文字色：  #F1F5F9（近白，对比度高）
次要文字：  #CBD5E1
弱文字色：  #94A3B8
品牌色：    #60A5FA（亮蓝，暗色背景下清晰）
品牌背景：  #1E3A5F
分隔线：    #334155
金色：      #D4A843
```

### 3.3 对比度验证（关键修复）
| 元素 | 前景色 | 背景色 | 对比度 | 是否达标 |
|------|--------|--------|--------|----------|
| 正文文字 | #111827 | #FFFFFF | 15.0:1 | ✅ AAA |
| 次要文字 | #4B5563 | #FFFFFF | 7.0:1 | ✅ AAA |
| 弱文字 | #6B7280 | #FFFFFF | 4.6:1 | ✅ AA |
| 品牌色文字 | #1E3A5F | #FFFFFF | 9.0:1 | ✅ AAA |
| 金句文字 | #1E3A5F | #F8F9FA | 8.8:1 | ✅ AAA |
| 暗色正文 | #F1F5F9 | #0F172A | 15.5:1 | ✅ AAA |
| 暗色品牌 | #60A5FA | #0F172A | 8.2:1 | ✅ AAA |

**结论：所有文字对比度均满足 WCAG AA 标准，绝大多数满足 AAA 标准。**

### 3.4 字体设计

#### 3.4.1 字体族
```
正文字体："Noto Serif SC", "Source Han Serif SC", "思源宋体", "SimSun", serif
标题字体："Noto Sans SC", "Microsoft YaHei", "PingFang SC", sans-serif
UI 字体：  "Noto Sans SC", "Microsoft YaHei", sans-serif
```

#### 3.4.2 字号阶梯
```

节标题：  26px / 22px，深黑色

```

#### 3.4.3 行高
```
正文行高：1.9
段落间距：1.5em
章节最大宽度：720px
```

### 3.5 书籍封面设计
- **文件**：`assets/images/cover.png`（800×1200）+ `cover_small.png`（400×600）
- **设计**：深藏青渐变背景 + 白色大字"搜商" + 金色装饰线 + 放大镜图标 + 作者信息
- **首页展示**：英雄区左侧展示封面，右侧展示书名和 CTA
- **可替换**：用户可自行替换 `assets/images/cover.png`

## 四、页面结构

### 4.1 首页
- **顶部导航**：书名 + 主题切换 + 开始阅读按钮
- **英雄区**：左侧书籍封面图片 + 右侧书名/副标题/CTA
- **核心理念**：卡片式简介 + 金句
- **金句墙**：精选金句网格
- **目录导航**：按 11 部分分组的章节入口
- **作者区**：作者卡片 + 统计数据 + 其他著作
- **页脚**：书名 + 作者 + 金句

### 4.2 阅读页
- **顶部栏**：书名 / 章节名 + 导航按钮 + 设置 + 沉浸式
- **左侧栏**：章节目录树（按部分分组）
- **主内容区**：章标题 + Markdown 渲染正文 + 翻页
- **右侧栏**：章节内 TOC
- **底部**：阅读进度条

### 4.3 沉浸式模式
- 隐藏顶栏、左栏、右栏
- 切换暗色主题
- 右上角浮层按钮（退出、主题）
- ESC / F 键退出

## 五、交互设计

### 5.1 核心交互
1. 章节切换（无刷新加载）
2. 沉浸式模式（F 键 / 按钮）
3. 主题切换（T 键 / 按钮，亮/暗）
4. 字号调节（小/中/大）
5. 阅读进度条
6. 章节内 TOC 跳转
7. 键盘快捷键（← → F T ESC）
8. 阅读位置记忆（localStorage）

### 5.2 动效
- 章节切换：淡入（300ms）
- 侧边栏：滑动展开（200ms）
- 按钮：hover 颜色过渡
- 封面：hover 微缩放
