# 规格文档：《搜商》图书阅读网站（v2 商务风格）

## 一、功能需求

### 1.1 首页功能（FR-HOME）

| 编号 | 需求 | 优先级 | 验收标准 |
|------|------|--------|----------|
| FR-HOME-01 | 展示书籍封面图片 | P0 | 英雄区展示 cover.png，可替换 |
| FR-HOME-02 | 展示书名及副标题 | P0 | 书名"搜商"+ 副标题 |
| FR-HOME-03 | 展示作者信息 | P0 | 姓名、头衔、简介 |
| FR-HOME-04 | 作者其他著作链接 | P1 | 两本著作，可点击跳转 |
| FR-HOME-05 | 核心简介卡片 | P0 | 一句话总结 + 核心理念 |
| FR-HOME-06 | 章节部分导航 | P0 | 按 11 部分组展示 |
| FR-HOME-07 | 精选金句墙 | P1 | 网格展示金句 |
| FR-HOME-08 | "开始阅读"按钮 | P0 | 跳转阅读页第一章 |
| FR-HOME-09 | "继续阅读"按钮 | P1 | 有记录时显示并跳转 |

## 二、非功能需求

### 2.1 视觉质量（NFR-VIS）— v2 新增
| 编号 | 需求 | 指标 |
|------|------|------|
| NFR-VIS-01 | 文字对比度 | 正文 ≥ 7:1（AAA），弱文字 ≥ 4.5:1（AA） |
| NFR-VIS-02 | 商务风格 | 深藏青主色，金色点缀，纯白背景 |
| NFR-VIS-03 | 封面图片 | 首页展示 cover.png |
| NFR-VIS-04 | 无青绿色 | 不使用 v1 的 teal 配色 |

### 2.2 性能（NFR-PERF）
| 编号 | 需求 | 指标 |
|------|------|------|
| NFR-PERF-01 | 首页加载 | < 2s |
| NFR-PERF-02 | 章节切换 | < 500ms |
| NFR-PERF-03 | 按需加载 | 仅加载当前章节 |

### 2.3 安全（NFR-SEC）
| 编号 | 需求 | 说明 |
|------|------|------|
| NFR-SEC-01 | XSS 防护 | DOMPurify 净化 |

### 2.4 无障碍（NFR-A11Y）
| 编号 | 需求 | 说明 |
|------|------|------|
| NFR-A11Y-01 | 语义化 | nav/main/article/aside |
| NFR-A11Y-02 | 键盘可操作 | 所有功能键盘可达 |
| NFR-A11Y-03 | 对比度 | WCAG AA |

## 三、内容需求

### 3.1 章节内容
- 42 篇：序言(1) + 正章(40) + 终章(1)
- 11 部分组

### 3.2 书籍封面
- 文件：`assets/images/cover.png`（800×1200）
- 已自动生成，可后续替换
- 首页英雄区展示

### 3.3 作者信息
- 宋秀强，深耕人力资源和职业发展领域
- 10年猎头、500强招聘经理、GCDF职业规划师、5000+服务求职者
- 两本其他著作

---

## 四、约束条件
- Tailwind CSS + Alpine.js（用户偏好）
- 纯前端，CDN 引入，无构建
- 简体中文文档，英文 snake_case 文件名
- 通过 HTTP 服务器运行

---

## 五、验收标准
1. 所有 P0 功能实现
2. 文字对比度满足 WCAG AA（正文满足 AAA）
3. 商务风格视觉（深藏青+金色+纯白）
4. 首页展示书籍封面
5. 42 章全部可加载
6. 浏览器控制台无错误
7. 响应式三档适配
