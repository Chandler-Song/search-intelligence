# 第23章：职场成长的真正飞轮

## 一、飞轮是什么

我先解释一下"飞轮"。

飞轮是一个物理概念——

想象一个巨大的轮子。你推它，一开始很费力，转得很慢。

但每推一下，它就快一点。

推到一定速度以后，它自己有惯性——你不推，它也在转。

你再推，它转得更快。

最后，它转得飞快，你只需要轻轻一推，就能让它持续高速运转。

——

这就是飞轮——

**起步难，但一旦转起来，惯性让你越来越省力，效果越来越大。**

商业上有个著名的"亚马逊飞轮"——

更低价格 → 更多客户 → 更多卖家 → 更多选择 → 更低价格（循环）

每一环都推动下一环，整个飞轮越转越快。

——

职场成长，也有一个飞轮。

但绝大多数人，没找到这个飞轮。他们在"推一个不会转的轮子"——再用力，也不转。

这一章，我给你真正的飞轮。

## 二、大多数人推的，是一个不转的轮子

我先给你看大多数人推的"轮子"——

> 努力 → 加班 → 累 → 休息 → 努力 → 加班 → 累 → 休息……

这个轮子，看起来在转，其实没转——

你努力了，但努力没有变成"能力"。

你加班了，但加班没有变成"经验"。

你累了休息，休息完继续努力——但你的"努力"和上次一样，没有升级。

**这个轮子转十年，你只是"更累"，不是"更强"。**

——

我有一个朋友，工作十年，一直在这个轮子里。

他每年都很努力，每年都加班，每年都累。

但他十年里，能力没怎么长——他只是"更熟练地做同样的事"。

他以为"努力就会成长"。

但努力不会自动成长。**努力只是提供能量，飞轮才能把能量转成成长。**

**没有飞轮的努力，是空转。**

## 三、真正的飞轮：六环

我给你真正的飞轮——

> 问题 → 搜索 → 解决 → 复盘 → 沉淀 → 能力

**第一环：问题**

你遇到一个真问题——不是重复的、不是已知的，是一个你不会的、需要你成长才能解决的。

这一环是飞轮的起点。没有真问题，飞轮不转。

**第二环：搜索**

你针对这个问题去搜——查资料、问 AI、找案例、看文档。

这一环你"找到解决这个问题的原料"。

**第三环：解决**

你用搜到的原料，结合自己的判断，把问题解决了。

这一环你"产生一次真实的解决经历"。

**第四环：复盘**

你回头看——这次解决的目标、结果、差距、原因、可提炼的经验。

这一环你把"一次经历"变成"一份经验"。

**第五环：沉底**

你把复盘出的经验，沉淀成"可复用的方法"——写下来、归档、形成模板。

这一环你把"一份经验"变成"可复用的资产"。

**第六环：能力**

下次遇到类似问题，你直接调用沉淀的方法，更快解决。

而且因为你的能力涨了，你能接到更复杂的问题——飞轮回到第一环，但这次的"问题"比上次更高级。

——

**这六环，每一环推动下一环。**

而且——

**最后一环"能力"，反过来推动第一环"问题"——能力涨了，你能接更难的问题，更难的问题解决以后，能力再涨。**

这就是飞轮——**越转越快，越转越大。**

## 四、飞轮的每一环都不能省

你可能会想——能不能省几环？

不能。省任何一环，飞轮就停。

**省"问题"**——你没事可做，飞轮不启动。

**省"搜索"**——你直接拍脑袋解决，解决质量低，下面几环都建立在低质量解决上。

**省"解决"**——你只搜不解决，搜到的东西没经过实践检验，下面复盘的是"想象"，不是"真实"。

**省"复盘"**——你解决了但不复盘，这次解决不变成经验，下次遇到类似问题你从零开始。**这是大多数人飞轮停的地方。**

**省"沉底"**——你复盘了但不沉淀，复盘的结论留在脑子里，慢慢忘。下次遇到类似问题，你"记得复盘过"但记不清结论，还是从零开始。

**省"能力"**——你沉淀了但不调用，沉淀的方法躺在文档里不用，你的实际行为没变，能力没真涨。

——

**任何一环省了，飞轮就停在那个环节。**

而大多数人，停在"解决"——他们解决问题，但不复盘、不沉淀、不形成能力。

所以他们的飞轮，每次都从"问题"重新开始，没有积累，没有加速。

## 五、一个真实案例：飞轮转起来是什么样

我给你看一个真实的飞轮案例。

我有一个朋友，2023 年还是普通运营。2024 年升主管。2025 年升经理。

他的飞轮是这样转的——

**第 1 圈（2023 年 Q1）**

问题：公司让他做一次用户增长活动，他没做过。

搜索：他搜了"用户增长活动"的案例、方法论、坑。

解决：他做了一次，效果中等。

复盘：他复盘——这次目标设定偏低、渠道选择保守、文案没抓住核心痛点。

沉淀：他写了一份"用户增长活动 SOP v1"。

能力：他有了"做这类活动"的初步能力。

**第 2 圈（2023 年 Q2）**

问题：又来一个增长活动，但这次预算更少、目标更高。

搜索：他这次搜得更快——因为他已经知道要搜什么。他还搜了"低预算增长"的专门案例。

解决：他用上次的 SOP + 这次的新搜，做得更快，效果更好。

复盘：复盘发现——这次渠道选对了，但文案还可以更精准。

沉淀：更新成"用户增长活动 SOP v2"。

能力：他对这类活动的"判断力"涨了——他能预判哪个渠道会有效。

**第 3 圈（2023 年 Q3）**

问题：领导让他带一个新人做增长活动。

搜索：他搜"怎么带新人做增长"。

解决：他用他的 SOP v2 教新人，新人做出来了。

复盘：复盘发现——SOP v2 还有几个地方不够细，新人会卡。

沉淀：更新成"SOP v3 + 新人培训手册"。

能力：他有了"带新人"的能力。

——

你看，三轮飞轮——

第 1 圈，他做出了一次中等效果的活动。

第 2 圈，他做出了一次好效果的活动，且更快。

第 3 圈，他带出了新人。

每一圈，他的"问题"都比上一圈更难——但他的"能力"也比上一圈更强，所以他能接住。

**这就是飞轮——问题变难，能力变强，互相推动，越转越快。**

——

三年以后——

他成了公司里"最懂数据驱动增长"的人。他有一套完整的 SOP，他能带团队，他能教别人。

他升到经理。

而他的同事——同样三年，还在"做活动"，没飞轮，没积累，没晋升。

## 六、飞轮和"努力"的差别

你可能会问——这和"努力"有什么差别？

差别巨大——

**努力是"投入能量"。飞轮是"把能量转成成长"。**

你可以很努力，但没有飞轮——你的能量全浪费了，没转成成长。

你可以不那么努力，但有飞轮——你的能量被高效转成成长，每次投入都产生复利。

——

我有一个朋友说——

"我过去十年，特别努力，但没飞轮。我每天加班到 11 点，但我的能力没怎么长——因为我解决问题但不复盘，复盘但不沉淀，沉淀但不调用。我的能量全漏掉了。"

"后来我建了飞轮——每天少做一件事，但每件事都走完六环。"

"一年以后，我做的事比以前少 30%，但我的能力比以前强一倍。"

"飞轮让我'少做事，多成长'。"

——

**飞轮不是让你更努力。飞轮是让你的努力产生复利。**

## 七、怎么启动你的飞轮

我给一个启动方法——

**第一步：找一个真问题。**

不是重复的事，是一个你"不会"的真问题。

**第二步：走完六环。**

问题 → 搜索 → 解决 → 复盘 → 沉淀 → 能力。

每一环都做。不省任何一环。

**第三步：把这个"沉淀"用在下一次。**

下次遇到类似问题，先看你沉淀的方法。

**第四步：让问题变难。**

当你能轻松解决一类问题以后，主动找更难的问题。

更难的问题 → 飞轮转到更高一圈。

——

**飞轮启动的前 3 圈最难。**

因为飞轮还没转起来，每一环你都不熟，你感觉"花时间不产出"。

但熬过前 3 圈，飞轮开始有惯性——你沉淀的方法开始复用，你复盘的速度变快，你解决新问题的速度变快。

3 圈以后，飞轮自己转。你只需要轻轻推。

——

**大多数人没飞轮，不是因为他们不想，是因为他们熬不过前 3 圈。**

前 3 圈"花时间不产出"，他们觉得"不如直接做事"，于是放弃。

**熬过前 3 圈的人，赢了。**

画一个你自己的飞轮——

针对每一个，问——

- 我复盘了吗？
- 我沉淀了吗？
- 我下次能复用吗？

如果三个都"是"——你的飞轮在转。

如果有"否"——你的飞轮停在那个环节。

**找出你停的环节，从下一次开始，把那个环节补上。**

补上以后，你的飞轮开始转。

而一旦开始转——

**你的成长速度，会让现在的你震惊。**
